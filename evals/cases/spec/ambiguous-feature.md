# Case: ambiguous feature

## Prompt

We need to make client records easier to review. Plan the work.

## Expected invariants

- Identify the affected actor and concrete review problem.
- Ask only for decisions that materially affect scope, or record low-risk assumptions.
- Define non-goals, acceptance criteria, affected surfaces, and validation needs.
- Do not create implementation tasks before the design is sufficiently settled.
- Resolve the discovery location from project conventions and persist the complete brief there.
- Read the artifact back and return a compact handoff rather than the complete brief.

## Expected output

One outcome sentence and no more than four short bullets covering the discovery artifact path, material assumptions or decisions, persistence validation, and the `bwh-spec` handoff.
